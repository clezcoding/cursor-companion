# Contributing to Cursor Companion

Thank you for your interest in contributing to **Cursor Companion**!

## Getting Started

1. **Fork and Clone**: Fork the repository on GitHub and clone it locally.
2. **Prerequisites**:
   - macOS (recommended for OpenUsage integration)
   - Node.js >= 18
   - [OpenUsage](https://github.com/openusage) running locally on port `6736`
3. **Branch Naming**:
   - `feat/feature-name`
   - `fix/bug-fix-name`
   - `docs/documentation-update`

## Commit Conventions

We follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` Introduces a new feature
- `fix:` Fixes a bug
- `docs:` Documentation only changes
- `chore:` Routine tasks or dependency updates
- `ci:` CI/CD workflow changes

## Pull Request Process

1. Ensure all skill validations and tests pass.
2. Update the README or documentation if you introduce new configuration options.
3. Open a Pull Request against `main`.
4. Our automated CI checks and Kodiak automerge will process qualifying PRs.
